# Hunter Bot

Многофункциональный Discord-бот для игровых сообществ. Он автоматизирует приватные голосовые комнаты, верификацию, уровни и статистику участников, а также интегрируется с Dota 2 и CS2/Faceit.

## Возможности

- Приветствия и уведомления о входе и выходе участников.
- Верификация новичков с выдачей ролей и проверкой формата ника.
- Временные голосовые комнаты с настройками и панелью владельца.
- Музыкальный плеер с Lavalink: поиск, очереди и плейлисты.
- XP за сообщения и голосовую активность, уровни и роли за уровень.
- Ежедневные голосовые стрики; при первом запуске после обновления прежние стрики однократно обнуляются.
- Статистика участников и сервера, журналы событий и резервные копии SQLite.
- Привязка Steam и Faceit, игровые сводки и уведомления о матчах.

Подробное описание архитектуры, модулей, команд и хранения данных находится в [BOT_OVERVIEW.md](./BOT_OVERVIEW.md).

## Требования

- Python 3.10 или новее.
- Discord-бот с включёнными привилегированными intents для участников, присутствия и содержимого сообщений.
- Для музыки — доступный Lavalink v4.
- Для соответствующих интеграций — API-ключи Steam и Faceit.

## Установка

```powershell
git clone https://github.com/CodeWritertB/hunter-bot.git
cd hunter-bot
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
Copy-Item .env.example .env
```

Заполните `.env` значениями для своего Discord-приложения, интеграций и серверов. Не добавляйте `.env`, токены, API-ключи, пароли, базу данных и журналы в Git.

## Настройка

Обязательная переменная:

| Переменная | Назначение |
|---|---|
| `BOT_TOKEN` | Токен Discord-бота |

Переменные интеграций:

| Переменная | Назначение |
|---|---|
| `STEAM_API_KEY` | Steam Web API для Steam-ссылок и обнаружения матчей Dota 2 |
| `FACEIT_API_KEY` | Faceit Data API для привязок и матчей CS2 |
| `LAVALINK_HOST` | Адрес сервера Lavalink v4 |
| `LAVALINK_PORT` | Порт Lavalink; по умолчанию `2333` |
| `LAVALINK_PASSWORD` | Пароль Lavalink |
| `LAVALINK_SECURE` | `true`, если для Lavalink нужны защищённые соединения (`wss`/`https`) |

Секреты и реальные адреса серверов не следует публиковать. В `.env.example` находятся только шаблонные значения.

## Настройка Discord

1. Создайте приложение и бота в [Discord Developer Portal](https://discord.com/developers/applications).
2. В разделе **Bot** включите **Server Members Intent**, **Presence Intent** и **Message Content Intent**.
3. Пригласите бота на сервер с разрешениями, необходимыми включённым функциям: просмотр и отправка сообщений, управление сообщениями, просмотр журнала аудита, управление каналами, перемещение и заглушение участников, управление ролями и никами, подключение к голосовым каналам.
4. Убедитесь, что роль бота расположена выше ролей, которыми он управляет.
5. После запуска используйте `/admin` для настройки каналов и ролей.

Выдавайте боту только необходимые разрешения. Административные команды доступны администраторам.

## Запуск

```powershell
python main.py
```

При первом запуске SQLite-файл `bot.db` и нужные таблицы создаются автоматически. База, бэкапы и логи хранятся локально и исключены из Git.

## Команды

### Участникам

| Команда | Назначение |
|---|---|
| `/help` | Список команд |
| `/rank [участник]` и `/top` | Уровень, XP и таблица лидеров |
| `/streak [участник]` и `/refresh_nick [участник]` | Голосовой стрик и обновление ника |
| `/music <запрос>` | Поиск или добавление музыки в очередь |
| `/link_steam <ссылка или имя>` и `/unlink_steam` | Привязка Steam для Dota 2 |
| `/dota [участник]`, `/dota_matches [участник]`, `/dota_week` | Статистика и матчи Dota 2 |
| `/link_cs <Faceit-ник>` и `/cs [участник]` | Привязка Faceit и статистика CS2 |

### Администраторам

| Команда | Назначение |
|---|---|
| `/admin` | Панель конфигурации сервера |
| `/set_info`, `/set_verify`, `/set_new_channel`, `/set_music_channel` | Настройка приветствий, верификации, лобби и музыки |
| `/set_log`, `/set_admin_log` | Каналы журналов событий |
| `/set_dota_channel`, `/set_cs_channel` | Каналы игровых уведомлений |
| `/set_level_role`, `/give_xp` | Настройка ролей уровней и ручная выдача XP |
| `/room_takeover <канал>` | Передача администратору управления временной комнатой |
| `/clear [число]`, `/userinfo [участник]`, `/serverinfo`, `/send_message` | Модерация и информация |
| `/reload [модуль]` | Перезагрузка одного или всех расширений |

## Автообновление и резервное копирование

Бот проверяет `origin/main` каждые 10 минут, выполняет только fast-forward обновление и перезагружает расширения. Автообновление требует Git-репозитория с настроенным `origin`; учитывайте это при самостоятельном развёртывании и контролируйте доверие к изменениям в ветке.

База данных копируется раз в сутки; хранятся последние семь копий. Для надёжного восстановления дополнительно организуйте резервирование вне машины с ботом.
