# Hunter Bot

Discord-бот: музыка с YouTube, приватные комнаты, верификация, XP, статистика, Dota 2 и CS2/Faceit.

## Запуск

Требуются Python 3.10+, FFmpeg и Node.js для музыки.

```sh
pip install -r requirements.txt
python main.py
```

Скопируйте `.env.example` в `.env` и укажите `BOT_TOKEN`. Включите необходимые privileged intents в Discord Developer Portal. Каналы настройте через `/admin`.

## BotHost

Задайте переменные окружения:

```env
BOT_DATA_DIR=/app/shared/hunter-bot
BOT_REQUIRE_EXISTING_DB=1
BOT_AUTOUPDATE=0
```

База хранится в `/app/shared/hunter-bot/bot.db`, резервные копии — в `backups/` рядом с ней. При первом запуске существующая база переносится из `data/bot.db` или `bot.db` в корне проекта. Перед первым обновлением сохраните копию базы. Если база отсутствует, защита останавливает запуск вместо создания пустой.

Обновляйте через панель BotHost и полностью перезапускайте процесс. Храните внешнюю копию базы.

## Музыка

Назначьте текстовый канал через `/admin` → «Музыка». Панель восстанавливается после перезапуска. Для добавления трека зайдите в голосовой канал и нажмите «Добавить трек» на панели, затем введите название или ссылку YouTube.

При ограничениях YouTube можно задать `YOUTUBE_COOKIES_FILE` — путь к локальному файлу cookies. Cookies не гарантируют снятие ограничений. Не публикуйте `.env`, cookies и базу в Git.
