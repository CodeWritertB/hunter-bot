# Hunter Bot

Discord бот для игрового сервера с системой приватных голосовых комнат, верификацией, XP, стриками, логированием, статистикой, интеграцией Dota 2 / CS2 и управлением CS2 сервером.

---

## Требования

- Python 3.10+

## Установка

```bash
pip install -r requirements.txt
```

## Настройка

Создай `.env` в корне проекта:

```env
BOT_TOKEN=твой_токен_бота
STEAM_API_KEY=твой_steam_api_ключ
FACEIT_API_KEY=твой_faceit_api_ключ
CS_RCON_PASSWORD=rcon_пароль_сервера
```

- Steam API ключ: [steamcommunity.com/dev/apikey](https://steamcommunity.com/dev/apikey)
- Faceit API ключ: [developers.faceit.com](https://developers.faceit.com)

## Запуск

```bash
python main.py
```

## Функции

### Верификация
При входе участник получает роль гостя. После нажатия кнопки и ввода ника в формате `Ник (Имя)` — получает роль участника. Одноразовая — повторно изменить ник нельзя.

### Приватные голосовые комнаты
Зайди в лобби-канал — бот создаёт комнату с панелью управления. Настройки сохраняются. Пустая комната удаляется автоматически. Панель восстанавливается после перезапуска.

Панель: ✏️ Название · 👥 Лимит · 👁 Видимость · 👑 Владелец · 📹 Видео · 🎤 Voice · 🔨 Баны · ⬆️ Поднять

### Музыкальный плеер
`/music [запрос]` — YouTube через Lavalink. Плеер закрепляется в канале, прогресс-бар обновляется каждые 10 секунд. Бот отключается через 5 минут простоя или когда все уходят из канала.

### XP система
- Сообщения: 10–25 XP (кулдаун 60 сек)
- Войс: 10 XP каждые 5 минут
- Повышение уровня — уведомление + автовыдача роли

### Стрики войса
- 🔥N — дней подряд заходил в войс (начинается с 1 в первый день)
- ❄️N — дней подряд не заходил в войс (начинается с 2)
- Сброс в 00:00 по МСК

### Dota 2
- Привязка Steam аккаунтов
- Статистика, последние матчи, топ героев
- Автоуведомление о начале матча с составом всех 10 игроков
- Live обновление счёта и режима игры
- Итоги с KDA, нетворсом, GPM, уроном
- Уведомление об изменении ранга
- Недельная статистика гильдии
- Дедупликация матчей сохраняется в БД (не дублируется после перезапуска)

### CS2 / Faceit
- Привязка Faceit аккаунтов
- Статистика ELO, K/D, HS%, WR
- Автоуведомление о матчах с разделением по командам и статистикой всех игроков

### CS2 Сервер
- Уведомления о входе/выходе игроков в реальном времени
- `/server` — текущий статус, карта, список игроков
- `/cs_admin` — панель управления: смена карты, кик, бан, сообщение в чат

### Панель управления `/admin`
Динамические кнопки — зелёные если настройка уже задана, серые если нет. Позволяет настроить все каналы и роли без команд.

### Логирование
- Лог сервера — сообщения, голосовые перемещения, изменения участников
- Админ-лог — баны, кики, роли, каналы
- Файловые логи в `logs/` — все события + отдельный файл ошибок

### Автообновление
Каждые 10 минут бот проверяет новые коммиты на GitHub. Если есть — делает `git pull` и перезагружает все модули без перезапуска.

### Автобэкап
БД копируется каждые 24 часа в `backups/`. Хранятся последние 7 копий.
