# Hunter Bot

**Игровой Discord-сервер с карточками матчей, приватными комнатами и управлением через кнопки.**

Hunter Bot объединяет Dota 2, CS2 / FACEIT, музыку, верификацию и активность участников.
Основные настройки доступны в `/admin`. Игровые профили подключаются через закреплённые панели.

## Что умеет бот

| Раздел | Возможности |
| --- | --- |
| Dota 2 | Привязка Steam, статистика, PNG-карточки матчей, инвентарь, рюкзак, улучшения и ссылки на Dotabuff |
| CS2 / FACEIT | Привязка FACEIT, PNG-карточки с фоном карты, составами, счётом и доступной статистикой |
| История Valve | Подключение Steam ID, кода доступа и share-кода, проверка новых кодов каждые пять минут |
| Голосовые комнаты | Создание временных комнат, настройка названия, лимита, видимости и владельца |
| Участники | Верификация, приветствия, XP, уровни и статистика |
| Стрики | Огоньки за голосовую активность и снежинки за пропуски по московским суткам |
| Музыка | Постоянная панель, очередь, кнопки управления, настройка YouTube |
| Администрирование | Выбор каналов и ролей, Markdown-аудит сервера, журналирование и резервные копии |

### Текущее состояние интеграций

- **Dota 2.** Доступность данных зависит от Steam и OpenDota. Мгновенное обнаружение начала любого матча не гарантируется. GSI в текущей версии не подключён.
- **Карточки Dota.** Портреты героев, Steam-аватары, шесть предметов, рюкзак и нейтралка отображаются при наличии данных. Серые улучшения означают отсутствие подтверждения поглощения. Проверка Dotabuff может быть ограничена самим сайтом.
- **FACEIT.** Итоговые показатели зависят от ответа API. Пока статистика матча недоступна, карточка показывает явно обозначенные показатели профиля. Названия CT/T используются только при явно переданной стороне, иначе отображаются названия команд.
- **Обычные матчи CS2.** Реализованы подключение истории и уведомления о новых share-кодах. Получение демо, счёта и полной статистики Valve ещё не подключено.
- **YouTube.** Обновление компонентов не гарантирует снятие ограничений YouTube или IP хостинга. Cookies являются секретом сессии.
- **Lavalink.** Команда `/lavalink_test` проверяет узел и поиск. Музыкальный плеер ещё не переведён на Lavalink.

## Установка

Нужен **Python 3.10 или новее**.

1. Загрузите исходники в каталог бота.
2. Создайте собственный `.env` по образцу `.env.example`.
3. Установите зависимости и запустите процесс.

```sh
python -m pip install -r requirements.txt
python main.py
```

В Discord Developer Portal включите необходимые privileged intents — Server Members, Presence и Message Content.

Для временных комнат и верификации нужны права управления каналами, перемещения участников, управления ролями и никами. Роль бота должна находиться выше ролей, которыми он управляет. Владелец сервера исключён из стриков.

## Переменные окружения

| Переменная | Назначение |
| --- | --- |
| `BOT_TOKEN` | Токен Discord-бота, обязателен |
| `STEAM_API_KEY` | Данные Steam, Dota и проверка истории CS2 |
| `FACEIT_API_KEY` | Привязка FACEIT и данные матчей |
| `BOT_DATA_DIR` | Постоянный каталог данных |
| `BOT_REQUIRE_EXISTING_DB` | `1` запрещает создание пустой базы при её отсутствии |
| `BOT_AUTOUPDATE` | `0` отключает встроенное Git-обновление |
| `FFMPEG_PATH` | Необязательный путь к системному FFmpeg |
| `YOUTUBE_COOKIES_FILE` | Необязательный путь к файлу cookies |
| `LAVALINK_URL`, `LAVALINK_PASSWORD` | Необязательные параметры проверки Lavalink |

### BotHost и постоянное хранилище

```env
BOT_DATA_DIR=/app/shared/hunter-bot
BOT_REQUIRE_EXISTING_DB=1
BOT_AUTOUPDATE=0
```

Рабочая база находится в `/app/shared/hunter-bot/bot.db`, копии — в `/app/shared/hunter-bot/backups/`.
При переносе проверяется сначала `data/bot.db`, затем `bot.db` в корне проекта. Оригинал сохраняется.

Для совершенно нового сервера без базы временно задайте `BOT_REQUIRE_EXISTING_DB=0`. После первого успешного запуска включите защиту обратно.

Бэкапы создаются при запуске, ежедневно и перед встроенным Git-обновлением. Для каждого типа остаются последние семь копий. Кнопка обновления хостинга выполняется вне процесса бота, поэтому перед ручной загрузкой нужна собственная копия данных.

## Ручное обновление на BotHost

1. Остановите бота.
2. Скачайте копию постоянного каталога `/app/shared/hunter-bot`.
3. Для полного обновления замените папки `cogs/`, `db/`, `assets/`, а также `main.py` и `requirements.txt`.
4. Сохраните рабочий `.env` и переменные окружения. Сравните их с `.env.example` и добавьте только недостающие настройки.
5. Установите зависимости из обновлённого `requirements.txt`.
6. Полностью перезапустите процесс и проверьте логи.

**Рабочую базу, каталог /app/shared и cookies не заменяйте файлами из исходников.**

Для обновления только последних визуальных изменений нужны следующие файлы.

| Обновление | Файлы |
| --- | --- |
| Карточки Dota | `cogs/dota.py`, `cogs/dota_card.py`, `cogs/dotabuff_status.py`, папка `assets/` |
| Карточки CS2 и FACEIT | `cogs/cs2.py`, `cogs/cs_card.py` |
| Подключение истории Valve | `cogs/cs_history.py`, `cogs/game_menu.py` |
| Общие зависимости | `requirements.txt` |

Если версия на хостинге заметно отстаёт, используйте полную замену исходников из шага 3.

## Первичная настройка в Discord

- `/admin` открывает выбор каналов и ролей.
- В музыкальном канале используется кнопка **Добавить трек**.
- В каналах Dota и CS2 закреплены меню привязки аккаунтов.
- **Матчи CS2 / Premier** открывает инструкцию и форму кодов истории Valve.
- `/server_audit` выгружает настройки для администратора.
- После запуска строка **Проверка стриков (запуск)** подтверждает сверку активности.

Данные карточек обновляются по мере появления информации у внешних API. После полного перезапуска сведения о некоторых активных матчах могут не восстановиться, поскольку текущие трекеры частично используют память процесса.

## Секреты и данные

Токен Discord, ключи API, cookies и коды доступа к истории храните вне публичного репозитория. Код истории CS2 можно удалить кнопкой отключения в меню. Доступ к базе и резервным копиям должен быть только у доверенных администраторов.
