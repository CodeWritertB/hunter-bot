# Hunter Bot

Discord бот с системой приватных голосовых комнат, верификацией, XP, стриками, логированием, статистикой и интеграцией Dota 2 / CS2.

---

## Требования

- Python 3.10+

## Установка

```bash
pip install -r requirements.txt
```

## Настройка

Создай `.env` в корне проекта:

```env
BOT_TOKEN=твой_токен_бота
STEAM_API_KEY=твой_steam_api_ключ
FACEIT_API_KEY=твой_faceit_api_ключ
```

- Steam API ключ: [steamcommunity.com/dev/apikey](https://steamcommunity.com/dev/apikey)
- Faceit API ключ: [developers.faceit.com](https://developers.faceit.com)

## Запуск

```bash
python main.py
```

## Функции

### Верификация
При входе участник получает роль гостя и видит только канал верификации. После нажатия кнопки и ввода ника в формате `Ник (Имя)` — получает роль участника и доступ к серверу.

### Приватные голосовые комнаты
Зайди в лобби-канал — бот создаёт комнату и отправляет панель управления прямо в канал. Настройки сохраняются для следующего раза. Пустая комната удаляется автоматически.

Панель управления:

| Кнопка | Действие |
|---|---|
| ✏️ Название | Переименовать (пресеты или своё) |
| 👥 Лимит | Установить лимит участников |
| 👁 Видимость | Скрыть/показать канал |
| 👑 Владелец | Передать права |
| 📹 Видео | Разрешить/запретить видео |
| 🎤 Voice | Разрешить/запретить голос |
| 🔨 Баны | Забанить участника (текущие + недавние) |
| ⬆️ Поднять | Поднять панель вниз (кулдаун 3 мин) |

### Музыкальный плеер
`/music [запрос]` — ищет трек на YouTube через Lavalink. Плеер закрепляется в канале, прогресс-бар обновляется каждые 10 секунд. Бот отключается через 5 минут простоя или когда все уходят из канала.

### XP система
- Сообщения: 10–25 XP (кулдаун 60 сек)
- Войс: 10 XP каждые 5 минут
- Повышение уровня — уведомление в чате + автовыдача роли

### Стрики войса
При первом заходе в войс за день стрик увеличивается на 1. Отображается в нике: `CodeWriter (Борис) 🔥5`. Если пропустил день — стрик сбрасывается в 00:00 по МСК.

### Dota 2 / CS2
- Привязка Steam/Faceit аккаунтов
- Статистика, последние матчи, топ героев
- Автоуведомление о начале матча с составом всех 10 игроков и их статистикой
- Live обновление счёта и режима игры
- Итоги матча с KDA, нетворсом, GPM, уроном
- Уведомление об изменении ранга
- Недельная статистика гильдии `/dota_week`

### Логирование
- Лог сервера (`/set_log`) — сообщения, голосовые перемещения, изменения участников
- Админ-лог (`/set_admin_log`) — баны, кики, роли, каналы
- Файловые логи в папке `logs/` — все события + отдельный файл ошибок

### Автобэкап
БД копируется каждые 24 часа в `backups/`. Хранятся последние 7 копий.
